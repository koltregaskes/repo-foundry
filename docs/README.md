# Repo Foundry Docs

This folder keeps the agent-facing operating notes for the public Repo Foundry lane.

## Files

- `PROCESS.md` - build, verify, publish, and handoff workflow
- `AUTORESEARCH.md` - automation chain and data refresh flow
- `KNOWLEDGE-BASE.md` - what the site knows, what stays private, and how the shelves map
- `STRUCTURE.md` - repo layout and where to edit things

## Fast path

If you need to work quickly:

1. read `../AGENTS.md`
2. read `../README.md`
3. read `PROCESS.md`
4. open the files named in `STRUCTURE.md`
