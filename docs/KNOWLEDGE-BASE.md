# Repo Foundry Knowledge Base

## Core product idea

Repo Foundry is a public discovery and editorial site for strong open-source repos. It is not the private manager console.

## Main public shelves

- AI command centre
- Workflow automation
- Agent workflow builder
- Video and media tooling
- Video and music tooling
- Productivity

## Main public routes

- `/`
- `/trending`
- `/repos`
- `/repos/:slug`
- `/lanes`
- `/lanes/:laneId`
- `/news`
- `/visualisations`
- `/resources/codex`
- `/about`

## Internal companion

The internal companion keeps:

- tracked repos
- backlog
- sessions
- ops
- knowledge
- cadence

Those internal surfaces are for manager-facing work and must not leak into the public build.
